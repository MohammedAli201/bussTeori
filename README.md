# Bus Theory Practice Page

A single-page browser exercise with bus-theory questions and supporting images.

## Run

Open `index.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

The page and its interaction logic are in `index.html`; question illustrations are under `images/`.

## Scope

Personal study tool. The questions are not presented as an official or current examination bank. Verify road rules against the relevant official material. No additional rights are granted to third-party question images by this README.
